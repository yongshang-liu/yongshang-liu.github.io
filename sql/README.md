# SQL Learning Hub · 中文课程

这是一个可直接在浏览器运行的 22 课 SQL 辅助课程。知识路线参考 Ben Forta 的《SQL必知必会》第 5 版，但讲解、题目、答案和金融数据均为本站原创，不包含教材章节原文或官方配套数据。

## 在线学习

打开 <https://yongshang-liu.github.io/sql-learning.html>。页面会加载 SQLite WebAssembly；选择课程后可修改示例并点击“运行 SQL”，无需安装数据库。查询与进度都保留在本地浏览器。

## 课程路线

1. 数据库、表与第一条查询
2. 检索、去重与限制行数
3. 排序查询结果
4. WHERE 精确筛选
5. 组合条件与集合筛选
6. 通配符与文本匹配
7. 计算字段与可读别名
8. 函数：文本、数值与日期
9. 汇总数据
10. 分组与分组后筛选
11. 子查询
12. 连接表
13. 高级连接与未匹配数据
14. 组合查询
15. 插入数据
16. 更新与删除数据
17. 创建与维护表结构
18. 使用视图封装查询
19. 存储过程的思想与替代方案
20. 事务与一致性
21. 游标思维与集合化处理
22. 高级 SQL：CTE、索引与负责任的数据使用

## 文件

- `course.js`：页面使用的 22 课原创讲解、示例、练习与参考答案。
- `financial-data.sql`：可单独下载的 SQLite 数据脚本，包含企业财务、银行贷款和股票交易三个案例域。
- `lesson-01.sql`：保留的最小入门脚本，便于课堂单独下载。

示例中的公司、个人、账户和交易全部为虚构数据，不对应真实机构或个人。
